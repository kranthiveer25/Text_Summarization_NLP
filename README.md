🧠 Text Summarization Web App | NLP Project
This project is a web-based Text Summarization tool that leverages Natural Language Processing (NLP) to automatically generate concise summaries from lengthy text inputs. Built with a clean and intuitive UI, the app allows users to:
✍️ Paste or type in custom text
📄 Upload documents for summarization
🎙️ Use voice input to dictate content
📌 Generate accurate and readable summaries in seconds
Key Features:
🔍 Efficient text summarization using NLP techniques
📊 Word count comparison between original and summarized content
🎤 Voice input integration for accessibility
💡 Ideal for summarizing news articles, blogs, scientific papers, and speeches
📱 Responsive and user-friendly design
Whether you're a student, researcher, or just someone trying to digest a long article, this tool makes reading easier and faster.
💻 Built as part of an academic project (ID: 2211CS020215) to demonstrate real-world applications of NLP and modern UI/UX principles.
